# Crowd-OMA-Dataset
Dataset of the crowdsensing study. 
The datasets provided here are raw and untrimmed. In the paper, only the first 300 seconds of each dataset is used.
Phone/Watch reference datasets are the datasets where the phones and watches are mounted on the structure.
Phone/Watch 4 run 2 bicycle are the datasets where the 4 pedestrians are jogging and 2 pedestrians are bicycling while carrying the phones and watches. 
Phone/Watch 2 walk 2 run 2 bicycle are the datasets where the 2 pedestrians walking, 2 pedestrians are jogging, and 2 pedestrians are bicycling while carrying the phones and watches. 
Due to the size, ground truth bridge dataset is in .rar file. This is the monitoring dataset of the bridge using professional grade SHM sensors (IOLITE-S system).
